# 親子進度與點數 App：完整功能規格

> 這份文件描述一個已經在使用中的家庭 App 的完整功能。
> **使用方式**：可以整份貼給 AI，請它照著做；也可以先刪掉不需要的段落（每一段大致獨立，第 4～13 節都是可選模組）。
> 建議貼上時加一句：「請先閱讀規格，提出檔案結構與實作計畫，等我確認後再分階段實作。」

---

## 1. 目標與使用情境

- 一位媽媽和兩個孩子使用（孩子人數可依需要調整）。
- 孩子用 iPad／iPhone 看今天要做什麼、勾選完成、累積點數兌換獎勵；媽媽用 iPhone 安排進度、核可、留言。
- 全部介面使用**繁體中文**，所有日期以**台灣時間（Asia/Taipei）**計算，以 `YYYY-MM-DD` 字串儲存。
- 介面要適合小孩：大按鈕、表情符號、正向不責備的語氣。
- 多台裝置**即時同步**（一台勾選，另一台立刻看到）。

## 2. 技術架構

- **前端**：純 HTML／CSS／JavaScript（ES modules），**不需要建置步驟**，PWA（可加到主畫面、可離線開啟）。
- **後端**：Firebase
  - Firestore（即時監聽 `onSnapshot`、離線快取）
  - Authentication：匿名登入
  - Cloud Functions（需要 Blaze 方案）：推播通知、排程、點數自動入帳、雲端語音
  - Cloud Messaging：網頁推播（需要 VAPID 金鑰）
- **託管**：GitHub Pages（hash 路由，例如 `#/k/kidA/home`，不需要伺服器設定）。
- Firebase JS SDK 從官方 CDN 載入，版本號固定。
- 所有資料放在 `families/{FAMILY_ID}/...` 底下（一個家庭一個 ID，寫在設定檔）。
- **Service Worker**：快取 App 外殼；每次更新要把版本號加 1。有新版時畫面出現「更新」列，使用者按下才換版。設定頁有「目前版本」和「檢查更新」按鈕。檢查新版時不使用瀏覽器快取。

## 3. 身分與安全（裝置配對）

- 每台裝置以 Firebase **匿名登入**取得固定的 uid。
- **第一次使用**：第一台裝置建立家庭（輸入兩個孩子的名字、設定 4～6 位數媽媽 PIN），自動成為「媽媽裝置」。
- **其他裝置**：顯示 4 位數配對代碼 → 媽媽在設定頁核可，選擇這台裝置給誰用（媽媽／某個孩子／兩個孩子共用）。
- 真正的權限由 `devices/{uid}` 決定，**用 Firestore 安全規則實施**：
  - 孩子裝置只能讀寫自己的資料。
  - 媽媽 PIN 只是媽媽裝置上的介面鎖，以 PBKDF2 雜湊儲存，孩子裝置讀不到。
- 進入 App 時選擇身分（媽媽／孩子A／孩子B）。只有一個可用身分時自動進入。
- 媽媽可以移除裝置；被移除的裝置要重新配對。
- 設定頁可以變更 PIN，也可以「鎖定」（這台裝置下次進入媽媽模式時要輸入 PIN）。

## 4. 版面與導覽

- 上方列：目前身分（點一下切換）。媽媽模式另有孩子切換鈕，上面顯示待處理數量徽章。
- 分頁：🏠 首頁、✅ 清單、📅 排程、💬 留言、⭐ 點數；媽媽多一個 ⚙️ 設定。手機在底部，平板在側邊。
- 徽章顯示待處理數量：
  - 媽媽：待核可、待確認進度、兌換申請、未讀留言。
  - 孩子：本週還沒排的進度、未讀留言。
- 每個孩子有名字、表情頭像、代表色，介面主色跟著孩子變。

## 5. 每日清單與核可（核心）

- 每天的清單由兩種來源**自動產生**：
  1. **每日固定事項**：媽媽設定，例如刷牙、洗碗。可以選星期幾、點數，也可以選「指定完成時間」。
  2. **已確認的進度**：當天排定的作業或任務。
- 清單項目的文件 ID 固定為 `{kidId}_{date}_{sourceId}`，所以重複產生也不會變成兩筆。
- 流程：孩子勾選 → **待核可** → 媽媽**核可**（入帳）或**退回**（可附原因）。
  - 送出後孩子不能自己取消，要請媽媽退回。
  - 已入帳的項目不能取消。
- 「全部完成」：當天每個項目都已核可時，發一次額外獎勵（點數可設定），每天最多一次。媽媽打開那天的清單時也會補發漏掉的獎勵。
- 項目被改期或取消時**不刪除**，改標「已改期／取消」，那天就不算全部完成。媽媽可以手動「從這天移除」。
- 媽媽可以一鍵「全部核可」。
- **指定完成時間**：過了時間才完成，點數減半，當天也不能拿全部完成獎勵。時間到之前 30 分鐘推播提醒。
- **自動順延**：前一天沒完成的進度移到隔天，標紅色「順延自 X/X」；原本那天的項目留著，標「沒完成，已順延」。
- **期限**：進度可以設截止日，期限前 2 天開始提醒。首頁有「快到期的作業」卡片。
- 清單可以看過去或未來的某一天（`#/k/kidA/checklist/2026-11-10`）。

## 6. 排程（進度）

- 一週或兩週檢視，可以前後翻頁，顯示每天的進度和課程。
- **進度**（任務）：標題、備註、科目、點數、日期、期限（選填）、指定完成時間（選填）。
  - 媽媽新增的進度直接是「已確認」。
  - 孩子也可以自己新增：狀態是「待媽媽確認」、0 點。媽媽確認時可以改點數、留建議，或退回。
- **本週進度**：媽媽訂內容與點數，孩子自己排到這週的某一天。
  - 排好就鎖定，孩子不能再改；媽媽可以「退回重排」。
  - 超過週日還沒排就是「逾期未安排」。
  - 還沒排的放在「本週待安排」區，依科目排序。
- **科目與顏色**：媽媽可以自訂，例如國語、數學、英文、才藝，所有地方都用科目顏色顯示。
- **課程**（例如才藝課）：沒有點數、不進入清單。可以每週重複（選星期、起訖日），也可以單次；可以「只取消這一次」。

## 7. 首頁（儀表板）

- 目前點數（大字）、等待核可的點數。
- **目標**：媽媽為每個孩子設一個目標，例如「存到 200 點換樂高」，用進度條顯示。
- 媽媽的待辦小藥丸，點一下就到對應頁面：待核可、待確認、兌換申請、本週還沒排、逾期。
- 快到期的作業、每日單字入口、課後小記入口、週末記事錄整理入口。
- 今日清單。
- **行程月曆**：月曆格上標示有課程的日子，點日期在下方列出當天行程。換月份或點日期時畫面不能跳動，iPhone 上要特別注意。
- 推播通知開啟提示（還沒開啟時才出現）。

## 8. 點數、兌換、目標

- **點數流水帳**：只新增、不修改、不刪除。目前點數＝所有紀錄的總和。
  - 類型：完成項目、額外獎勵、手動調整、兌換、課後小記、記事錄整理。
  - 依類型篩選，每筆顯示日期與入帳時間。
- 媽媽可以手動加減點並寫原因。
- **兌換項目**：媽媽設定名稱、表情、點數，可以下架。
- **兌換申請**：孩子申請時點數**先預留**（可用點數＝目前點數－申請中）。
  - 媽媽核可才正式扣點；退回就還給孩子。
  - 孩子可以取消自己申請中的項目。
  - 申請的點數必須等於兌換項目的點數（安全規則檢查）。

## 9. 留言板

- 每個孩子和媽媽一個對話串，即時顯示。
- 訊息不能修改或刪除，最多 500 字。
- 已讀時間分開記錄（媽媽、孩子），用來計算未讀徽章。

## 10. 每日單字（可選模組）

- **字庫**：媽媽新增，指定給哪個孩子；也可以先不指定。
  - **補習班單字**：有考試日，優先學、照輸入順序。
  - **一般字庫**：例如 Flyers、國中 2000 字，可以選隨機或照順序。
  - 匯入格式：一行一個字，`單字｜詞性｜中文｜例句`；詞性與例句可省略，斜線分隔的多個字會拆開。
  - 每份字庫顯示學習進度，學完顯示 🎉。考試日已過的補習班單字收成一列。
- **每天**：新單字 N 個（預設 5）加上到期的複習字。完成給點（預設 2），一次全對再加點（預設 2）。清單上自動多一項「📖 每日單字」。
- **間隔重複（SRS）**：熟練度 0～6，對應不同的複習間隔；答錯就降級。
- **題型**：
  - 新單字：選意思、拼字。
  - 複習（媽媽可以勾選要用哪些）：看中文拼字（固定會有）、例句填空（拼字或選擇）、聽音拼字、字母重組、配對。
  - 補習班單字在考試前一律出「聽音拼字」，和老師唸、孩子寫的考法一樣。
  - 填空題直接顯示中文意思；提示要點了才出現（第一個字母和字數）。
  - 選擇題的干擾選項優先挑詞性相同的字。
- **發音**：雲端自然語音（Cloud Function 呼叫 Google Text-to-Speech，結果快取在 Firestore，每日有字數上限），也可以選裝置內建的聲音。可以調慢速。iPhone 上第一次播放要由點按啟動。
- 「學過的單字」清單：隨時可以聽發音，也能看下次什麼時候複習。
- 練習中途離開可以繼續；完成後不能再改結果。

## 11. 課後小記（可選模組：給上特殊課程的孩子）

### 11.1 每日小記

- **課表**：媽媽設定哪個孩子要寫，以及每週哪幾天上哪一類課、幾堂。類別是人文、數理、專題研究。例如：週二 數理1＋專題1，週四 專題1＋人文2，週五 數理1。
- 上課日的清單多一列「📝 課後小記」：
  - 狀態是中性的「還沒寫」，不標紅、不順延。
  - 不算在全部完成裡，自己沒有點數（點數由小記本身入帳）。
- **填寫流程**（基本版目標約 30 秒）：
  1. 哪一堂最有印象（只有一類課時自動選好）
  2. 心情：有趣、好玩、開心、還好、累、無聊。選了之後可以再細分，並顯示**一個**追問（可不寫）。
     - 「累」：不追問，只顯示「累的時候也記得留下一句，很棒」。
     - 「無聊」：兩層追問。第一層選原因（早就會了、沒興趣、不喜歡、跟不上、不確定怎麼做、太久了、其他），選了後先回應「謝謝你說實話，這很有用」，再問一個第二層問題。
     - 寫的字裡出現「無聊」「累」時，也會補上對應的追問。
  3. 📚 今天學到了什麼（一句話）
  4. 選填：✨ 我覺得有趣的是…、❓ 我想知道…、🧭 專題進度（有專題課的日子才出現）
  5. 「也想記另一堂」：另一類課＋一句話（不影響點數）
- **完成程度與點數**：只看有沒有填，不評分。
  - 基本＝心情＋學到（+1）
  - 進階＝再寫「有趣」或「想知道」其中一項（+2）
  - 完整＝兩項都寫（+3）
  - 點數可設定，由**伺服器**依內容自動入帳，不用核可，**只加不扣**：升級時補差額，改少或改成休息都不扣。
- 「今天休息」按鈕：不扣點，這週內想寫還能回來寫。
- **補寫**：同一週、今天以前的上課日都可以補寫，補寫可設定少給幾點（預設 0）。
- **輕鬆版的日子**（例如週五）：只顯示基本版，要按「想多寫一點」才展開。
- 還沒送出的草稿存在裝置上，關掉 App 也不會不見。
- **溫和提醒**：上課日到了設定時間（預設 18:30），如果還沒寫、也沒選休息，推播一次，不再催第二次。
- 媽媽可以查看每一篇並留言，孩子會收到通知。

### 11.2 週末記事錄整理

- 每一類課列出這週相關的小記。那類課這週沒寫的話，顯示回想問題。
- 開頭句：
  - 一次 3 句，盡量不同類型，可以「換一組」，用完再從頭；點一下就放進文字框。
  - 類別自己的句子不夠時，用通用句。
  - 這週選過「沒興趣、不喜歡、跟不上」的話，第一組一定有一句低壓力的開頭。
- 孩子可以新增自己的開頭句。
- 自動存草稿；**週六、週日**按「完成」給點（預設 +3，伺服器入帳，每週一次）。
- 可以複製文字、列印（列印只印整理內容），方便抄到學校的記事錄。

### 11.3 媽媽功能

- 小記頁的「📊 這週摘要」：上課幾天、寫了幾天、休息、還沒寫、心情分布、完成程度、孩子寫的「我想知道」。
- **敏感提示**（只有媽媽看得到）：同一類課連續 N 週（預設 2）都出現「沒興趣、不喜歡、跟不上」時，提示「這類課程近幾週有較多類似回應，可以找時間聊聊」。
- **提示文字編輯器**：心情、細分、追問、無聊的選項與追問、開頭句、回想問題都可以改，也可以恢復預設。
- **匯出 CSV**：每日小記或記事錄整理，預設這學期（8/1–1/31、2/1–7/31）。檔案加 BOM，Excel 才能正確顯示中文。在手機上用分享選單存檔。

### 11.4 文字設定檔

所有孩子看到的文字放在 `data/journalPrompts.json`，媽媽在 App 內修改後存在 Firestore 並覆蓋這個檔案。結構：

```json
{
  "feelings": [{ "id": "interesting", "label": "有趣", "refinements": ["驚訝", "好奇"], "followUp": "是哪一個畫面讓你這樣覺得？", "sentenceStarter": "我覺得有趣，是因為……" }],
  "boringFlow": {
    "firstLevelQuestion": "是哪一種呢？",
    "responseMessage": "謝謝你說實話，這很有用",
    "reasons": [{ "id": "too_hard", "label": "這個有點難，我跟不太上", "secondLevel": "哪一個地方卡住了？" }],
    "sensitiveReasonIds": ["not_interested", "dislike", "too_hard"],
    "parentHint": "這類課程近幾週有較多類似回應，可以找時間聊聊"
  },
  "weeklyStarters": { "humanities": [{ "id": "h1", "type": "surprise", "text": "這週我最驚訝的是……" }], "math_science": [], "project": [], "general": [], "lowPressure": [] },
  "starterRules": { "showPerRound": 3, "preferDifferentTypes": true, "allowRefresh": true, "fallbackPools": ["general", "lowPressure"], "lowPressureTriggerReasonIds": ["not_interested", "dislike", "too_hard"], "allowCustomStarters": true },
  "weeklyPage": { "recallPrompts": ["這週的課，還記得老師講了什麼嗎？"], "doneMessage": "整理好了！可以照著抄到記事錄上 ✍️" }

```

原則：語氣正向、不責備；不做拍照功能；點數只看有沒有填，不看寫得好不好。

## 12. 推播通知與排程（Cloud Functions）

- 每台裝置開啟通知後，把推播權杖寫到 `pushTokens/{自己的uid}`。只能寫自己的，用戶端都讀不到。
- 媽媽的通知送到媽媽裝置；孩子的通知送到配對給那個孩子、而且不是媽媽的裝置。
- **媽媽會收到**：孩子自己排了進度、孩子勾選完成（同一天合併成一則「共有 N 項等你核可」）、兌換申請、留言、前一天沒完成而順延的作業（早上）、作業過了期限。
- **孩子會收到**：
  - 進度被確認或退回、點數入帳或退回、額外獎勵、兌換結果、媽媽的留言、媽媽新增本週進度
  - 放學後提醒（預設 16:30）：順延的作業、2 天內到期的作業
  - 指定時間前 30 分鐘提醒
  - 每日提醒（預設 20:00）：還沒完成的項目、還沒排的本週進度、明天截止的作業
  - 課後小記：入帳通知、媽媽回應、上課日的溫和提醒
- **勿擾時段**（預設 22:00–07:00）：時段內的通知先排隊，結束後再送；同一類只送最新一則。
- 每一類通知都能在設定裡關閉，提醒時間以 30 分鐘為單位調整。
- 排程每 30 分鐘執行一次，依序做：自動順延 → 補發排隊的通知 → 放學後提醒 → 指定時間提醒 → 每日提醒 → 課後小記提醒。每種每天只發一次，用 `meta/pushState` 記錄。
- 用 Firestore 觸發的函式：進度、清單項目、流水帳、兌換、留言、課後小記、記事錄整理。

## 13. 離線

- Firestore 離線快取：離線時可以瀏覽、勾選，連線後自動同步。
- 需要交易的動作（核可、兌換、匯出）離線時提示「需要網路」。
- 畫面上方顯示「離線中」。

## 14. 設定頁（媽媽）

- 🔔 通知：這台裝置開啟推播、各類通知開關、提醒時間、勿擾時段
- 🔗 裝置管理：配對申請（核可或拒絕）、已配對的裝置（移除）
- 📋 每日固定事項（依孩子分頁）
- 📖 每日單字：字庫管理、每天新字數、點數、全對加點、複習題型、新字順序

## 16. 安全規則重點

- 未配對的裝置只能申請配對。孩子裝置只能讀寫自己的資料。
- **流水帳只有媽媽或伺服器能新增，任何人都不能修改或刪除。** 用固定的流水帳 ID，避免重複入帳。
- 孩子能做的事：
  - 勾選只能把狀態改成「待核可」，送出時間必須是伺服器時間；不能自己核可。
  - 補建清單項目時，點數和指定時間必須和來源一致。
  - 新增進度必須是「待確認」、0 點；本週進度只能排在同一週、期限之前，排定後不能自己改。
  - 兌換申請的點數必須等於兌換項目；只能取消自己的申請。
  - 留言只能以「孩子」身分發言。
  - 單字練習的答錯紀錄不能刪，完成後不能改。
  - 小記與記事錄的點數欄位只有伺服器能寫，媽媽留言只有媽媽能寫。

## 17. 測試建議

- 用 Firebase 模擬器（Firestore、Auth）做安全規則測試，每條規則都要有「可以」和「不可以」的案例。
- 純邏輯（日期、間隔重複、指定時間、小記層級、開頭句挑選、CSV）寫單元測試。
- Cloud Functions 的觸發邏輯直接呼叫函式，在模擬器裡測：模擬器模式下不真的發推播，改寫到一個紀錄集合。
- 用 Playwright 以 iPhone 尺寸跑主要流程：建立家庭 → 配對 → 安排進度 → 孩子勾選 → 媽媽核可 → 點數與獎勵。

## 18. 建議的實作順序

1. 第一階段：配對與身分、每日固定事項、進度排程、每日清單與核可、點數流水帳、首頁
2. 第二階段：留言板、課程與月曆、科目顏色、兌換與目標、本週進度
3. 第三階段：推播通知、每日提醒、勿擾時段、離線、更新提示
4. 之後的模組（彼此獨立）：自動順延與期限、指定完成時間、每日單字、課後小記、週末記事錄整理
